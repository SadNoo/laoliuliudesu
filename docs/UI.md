# Web 界面

视觉方向继承旧项目 Web 控制台的深色青色/橙色体系、左侧导航和状态卡片，但页面
内容已经按本项目范围重新设计，没有复制旧项目提示词或 AI 分析模块。

## 页面

1. 登录：品牌说明、用户名、密码和安全状态。
2. 首次改密：一次性密码登录后强制打开，不完成不能访问业务页面。
3. AI 解读：解释当前确定性统计并展示当前账号的历史解读记录；导航位于生肖分析上方。
4. 生肖分析：最新期开奖条件、带号码次数明细的六个生肖卡片和十二生肖完整排名。
5. 历史分析：选择历史期号，查看严格截止到该期重算的生肖与号码次数。
6. 开奖数据：2026 年第 048 期起 6+1 数据分页列表。
7. 用户授权（管理员）：创建子用户、一次性展示临时密码、启停账号。
8. 数据与 AI（管理员）：手工历史/增量同步、同步记录、OpenAI 兼容配置。

## 交互原则

- 所有统计同时显示样本数、次数和历史频率。
- 生肖号码明细使用“兔[5（3），17（2）]”形式，先按次数、再按号码排序。
- 页面固定显示“历史条件频率，不保证未来开奖”。
- AI 加载、同步、登录和保存期间禁用重复提交。
- 错误展示稳定错误码语义和可复制的 Request ID，不展示堆栈或秘密。
- 桌面使用固定侧栏；窄屏侧栏折叠，表格可横向滚动。
- Token 不写入 LocalStorage 或 SessionStorage。
